# codyssey-python-quiz

## 1. 프로젝트 소개
Python을 활용하여 터미널에서 실행하는 4지선다형 퀴즈 게임을 만드는 프로젝트입니다.

## 2. 퀴즈 주제
주제: Python 기초 지식 퀴즈

선정 이유: Python을 학습하면서 기본 문법과 함수, 자료형 등을 재미있게 복습하기 위해 선정했습니다.

## 3. 주요 기능
- 퀴즈 풀기 (기본 문제 5개 작성, 실행 테스트 필요)
- 퀴즈 추가 (구현 예정)
- 퀴즈 목록 확인 (구현 예정)
- 최고 점수 확인 (구현 예정)
- 데이터 저장 및 불러오기 (구현 예정)
- 프로그램 종료 (구현 완료)

## 4. 실행 방법
Python 3.10 이상 필요
python main.py

실행하면 다음 메뉴가 표시됩니다.


===== 나만의 퀴즈 게임 =====
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료


## 5. 프로젝트 파일 구조
- `main.py`: 프로그램 실행
- `quiz.py`: Quiz 클래스 (문제 출력 및 정답 확인)
- `quiz_game.py`: QuizGame 클래스 (메뉴 및 게임 진행)
- `state.json`: 퀴즈와 최고 점수 저장 (구현 예정)
- `README.md`: 프로젝트 설명
- `.gitignore`: Git 관리에서 제외할 파일 설정

## 6. 데이터 저장
`state.json` 파일에 UTF-8 형식으로 퀴즈 목록(`quizzes`)과 최고 점수(`best_score`)를 저장할 예정입니다.

현재는 기본 퀴즈 5개를 Python 코드에 작성했으며, JSON 파일 저장 및 불러오기 기능은 추후 구현합니다.
