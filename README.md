# codyssey-python-quiz

## 1. 프로젝트 개요

Python을 사용하여 터미널에서 실행하는 4지선다형 퀴즈 게임을 제작한다.

기본 퀴즈를 풀고, 새로운 문제를 추가하고, 최고 점수를 확인할 수 있도록 구현하였다.

## 2. 퀴즈 주제

**Python 기초 지식 퀴즈**

선정 이유: Python을 학습하면서 기본 문법, 함수, 자료형 등을 재미있게 복습하기 위해 선택하였다.

## 3. 개발 환경

- Git / GitHub
- Visual Studio Code (VS Code)
- Windows / PowerShell

## 4. 파일 구조

```text
codyssey-python-quiz/
├── main.py
├── quiz.py
├── quiz_game.py
├── state.json
├── README.md
└── .gitignore
```

- `main.py`: 프로그램 실행
- `quiz.py`: Quiz 클래스, 문제 출력 및 정답 확인
- `quiz_game.py`: QuizGame 클래스, 메뉴 및 게임 진행
- `state.json`: 퀴즈 목록과 최고 점수 저장
- `README.md`: 프로젝트 설명 및 진행 기록
- `.gitignore`: Git 추적 제외 파일 설정

※ `state.json`은 저장 기능 실행 시 생성된다.

**[캡처 예정: VS Code 프로젝트 파일 구조]**

## 5. 실행 방법

프로젝트 폴더에서 다음 명령어를 실행한다.

```bash
python main.py
```

## 6. 주요 기능

- 메뉴 출력 및 선택
- 기본 퀴즈 5개 제공
- 퀴즈 풀기 및 정답 판별
- 새로운 퀴즈 추가
- 등록된 퀴즈 목록 확인
- 최고 점수 확인 및 갱신
- 입력값 앞뒤 공백 처리
- JSON 파일 저장 및 불러오기
- 프로그램 종료

## 7. 데이터 저장

- 파일명: `state.json`
- 저장 위치: 프로젝트 최상위 폴더
- 인코딩: UTF-8
- `quizzes`: 문제, 선택지 4개, 정답 번호 저장
- `best_score`: 최고 점수 저장

### 저장 기능

- 새로운 퀴즈 추가 시 저장
- 최고 점수 갱신 시 저장
- 프로그램 종료 시 저장

### 불러오기 기능

- 프로그램 시작 시 저장 파일 확인
- 저장 파일이 있으면 퀴즈 목록과 최고 점수 복원
- 파일이 없으면 기본 퀴즈 5개 사용
- 파일 읽기 오류 발생 시 기본 퀴즈 사용

※ 저장 및 불러오기 코드는 작성했으며, 최종 재실행 테스트가 필요하다.
