# codyssey-python-quiz

## 1. 프로젝트 소개
Python을 활용하여 터미널에서 실행하는 퀴즈 게임을 만드는 프로젝트입니다.

## 2. 퀴즈 주제
주제: 미정

선정 이유: 미정

## 3. 주요 기능
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- 데이터 저장 및 불러오기
- 프로그램 종료

## 4. 실행 방법
Python 3.10 이상 필요
python main.py


## 5. 프로젝트 파일 구조
- `main.py`: 프로그램 실행
- `quiz.py`: Quiz 클래스
- `quiz_game.py`: QuizGame 클래스
- `state.json`: 퀴즈와 최고 점수 저장
- `README.md`: 프로젝트 설명

## 6. 데이터 저장
`state.json` 파일에 UTF-8 형식으로 퀴즈 목록(`quizzes`)과 최고 점수(`best_score`)를 저장합니다.
